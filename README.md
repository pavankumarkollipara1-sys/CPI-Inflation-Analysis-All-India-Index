# CPI-Inflation-Analysis-All-India-Index
Analyzed CPI data (2013-2023) across Rural, Urban, and Combined sectors covering 25+ commodity groups in Excel. Calculated YoY inflation, identifying 2022 as the peak at 6.62% due to global supply shocks. Showed Food &amp; Beverages make up ~50% of CPI weight. Built pivot-based summaries and insight narratives for clear, data-driven conclusions.
